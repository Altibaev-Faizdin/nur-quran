## 2. Глубокий анализ специфики Quran-приложения

### 2.1. Целостность арабского текста Корана
- **Количество сур и аятов:** Проверено скриптом в `frontend/shared.js` — ровно 114 сур, суммарно 6 236 аятов по канонической нумерации Hafs/Kufi.
- **Источник текста:** Динамически запрашивается из публичного API `api.alquran.cloud` (редакция `quran-uthmani`, соответствующая каноническому тексту Tanzil). Ручных искажений в самом арабском тексте в репозитории нет, так как текст не хранится локально.
- **Проблема отсутствия оффлайн-текста:** Если у пользователя пропадает интернет, `fetchSurahData()` делает попытку запросить резервный URL с того же самого хоста `api.alquran.cloud`, терпит крах и выбрасывает необработанное исключение:
  ```javascript
  // frontend/shared.js:86-88
  const singleUrl = `https://api.alquran.cloud/v1/surah/${surahNum}`;
  const res = await fetch(singleUrl);
  const d = await res.json(); // При падении сети вызовет TypeError
  ```
- **Дублирование Басмалы в Аль-Фатихе:**
  В `frontend/pages/quran.html:183` элемент `#rbis` («Бисмилляхи р-Рахмани р-Рахим») скрывается только для 9-й суры:
  ```javascript
  document.getElementById('rbis').style.display = n === 9 ? 'none' : 'block';
  ```
  Однако в Суре 1 (Аль-Фатиха) Басмала официально является **первым аятом**. В результате на экране отображается две Басмалы подряд: сначала в блоке `#rbis`, а сразу под ней — как Аят 1.
  *Доказательство:* `frontend/pages/quran.html:183`.

### 2.2. Переводы и Тафсиры
- **Источники:**
  - Английский: `en.asad` (Muhammad Asad).
  - Русский: `ru.kuliev` (Эльмир Кулиев).
  - Узбекский: `uz.sodik` (Шейх Мухаммад Садык Мухаммад Юсуф).
- **Смещение аятов:** Соответствие аятов строковое по `numberInSurah`, сдвига нумерации не обнаружено при ответе API.
- **Отсутствие метаданных и копирайтов:** На странице `quran.html` нигде не указано имя переводчика и источник перевода, что нарушает правила атрибуции и академической честности религиозных текстов.

### 2.3. Вёрстка, RTL и Типографика
- **Направление текста:** Блоки `.aarb` и `.ayah-arab` имеют `direction: rtl; text-align: right;`.
- **Шрифт:** В `shared.css` и `shared.js` подключены `'Scheherazade New', 'Amiri Quran', 'Amiri', serif`.
- **Межстрочный интервал:** В коммите `14b4733` интервал для арабского текста увеличен до `line-height: 2.2` — огласовки (ташкиль) отображаются разборчиво и не наезжают на соседние строки.
- **Смешанный LTR/RTL поиск:** В поле поиска `quran.html` при вводе арабского текста курсор перескакивает, так как у инпута нет динамического переключения `dir="auto"`.

### 2.4. Аудиосистема Корана
- **Хардкод чтеца в читалке:**
  В `frontend/pages/quran.html:227` в функции `playAyahQuran` жестко прописан URL Alafasy:
  ```javascript
  aud.src = `https://cdn.islamic.network/quran/audio/128/ar.alafasy/${num}.mp3`;
  ```
  Какой бы чтец ни был выбран в настройках или профиле, при чтении Корана ВСЕГДА играет только Мишари аль-Афаси.
- **Race Condition при переходе на следующую суру:**
  В `frontend/pages/quran.html:268-271`:
  ```javascript
  } else if (CUR.n < 114) {
    openS(CUR.n + 1);
    playAyahQuran(CUR.n + 1, 1);
  }
  ```
  Функция `openS()` асинхронная (загружает аяты по сети), а `playAyahQuran()` запускается синхронно сразу после вызова `openS()`. В результате аудио начинает играть до того, как построился DOM нового списка аятов.
- **Неполный аудиофонд чтецов:**
  Чтецы `sherif_mostafa` и `abdurrahman_mossad` имеют лишь несколько сур. В `frontend/audio/` лежит 8 и 2 MP3-файла соответственно. При попытке послушать несохраненную суру запрос уходит на `server16.mp3quran.net/mossad/002.mp3` и возвращает `HTTP 404`.

### 2.5. Времена намаза и оффлайн-расчет
- **Высокие широты:** Формула `calculateOfflinePrayerTimes()` в `frontend/shared.js:377-383`:
  ```javascript
  var sunAngleTime = function(angle, direction) {
    var val = (-Math.sin(rad(angle)) - Math.sin(rad(latitude)) * Math.sin(rad(delta))) /
              (Math.cos(rad(latitude)) * Math.cos(rad(delta)));
    if (val > 1 || val < -1) return null;
  ```
  Для городов выше 48–50° с.ш. (Санкт-Петербург, Казань, Уфа, Лондон, Осло) в летний период угол солнца не опускается ниже 18°, `val > 1`, функция возвращает `null`, и на экране отображается `--:--`. Отсутствуют правила адаптации (Angle-based / One-Seventh rule).
- **Мазхаб времени Аср:** Расчет жестко зашит по формуле одинарной длины тени (Шафии/Малики/Ханбали). Время Аср по мазхабу Абу Ханифы (двойная тень) выбрать невозможно.

### 2.6. Компас Киблы (`qibla.html`)
- **Блокировка на iOS Safari:** Код пытается напрямую подписаться на `window.addEventListener('deviceorientation')` (`qibla.html:310`). Начиная с iOS 13, Apple требует предварительного запроса `DeviceOrientationEvent.requestPermission()` по клику пользователя. Без этого стрелка компаса на iPhone замирает на 0°.
- **Антипаттерн prompt():** Ручная смена координат реализована через браузерный `prompt()` (`qibla.html:285-288`), который блокируется мобильными WebView и Telegram/WhatsApp встроенными браузерами.

### 2.7. Авторизация, Регистрация и Закладки
- **Критический дефект деплоя:** В `login.html:334` и `register.html:359` захардкожен абсолютный URL:
  ```javascript
  const res = await fetch(`http://localhost:8000/api/auth/login/`, ...);
  ```
  В продакшне при заходе на `https://...` браузер блокирует эти запросы политикой Mixed Content (HTTPS -> HTTP) либо получает `Connection Refused`.
- **Ложный вход в систему:**
  В блоке `catch` любого сбоя сети (`login.html:352-358`):
  ```javascript
  localStorage.setItem('access_token', 'demo-session-token');
  localStorage.setItem('username', u);
  showToast('Бэкенд временно оффлайн. Включен демо-режим...');
  ```
  Пользователь считает, что создал аккаунт или успешно вошел со своим паролем, однако аккаунт в базе данных не создается, и при очистке кэша браузера все закладки исчезают навсегда.

### 2.8. Локализация (i18n)
- Файл `frontend/i18n.js` содержит всего 32 ключа. Все они относятся к меню и заголовкам модалок.
- Заголовки карточек, описание инструментов, кнопки плеера, сообщения об ошибках, дни недели, названия молитв и статусы отображаются исключительно на английском языке независимо от выбора русского или узбекского интерфейса.
