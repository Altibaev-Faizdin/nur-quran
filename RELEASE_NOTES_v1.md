# Release Notes - Noor Al-Quran v1.0.0-rc1

## Что появилось (New Features)
- Полный текст Корана на арабском языке со смысловыми переводами на английский, русский и узбекский языки.
- Продвинутый аудиоплеер с поддержкой 10 различных всемирно известных чтецов.
- Система глубоких ссылок (Deep-linking) для возможности поделиться конкретным аятом.
- Расчет времени намаза на основе геолокации (через API Aladhan).
- Интеграция сборников Хадисов.
- Интерактивный счетчик Тасбиха с автосохранением в LocalStorage.
- Авторизация и регистрация пользователей (JWT).
- Синхронизация закладок с базой данных (на стороне сервера).
- Компас Киблы, раздел Дуа и 99 Имен Аллаха.
- Темная тема с ночным дизайном.

## Какие функции работают (What's Working)
- **Чтение Корана и аудио:** Загружается синхронно, плеер работает стабильно, переключение сур без задержек.
- **Время намаза:** Автоматически подстраивается под браузер пользователя.
- **Авторизация:** Безопасно выдаются и обновляются токены, реализован Refresh.
- **Закладки (Bookmarks):** Сохранение, просмотр и удаление привязаны строго к текущему авторизованному пользователю.
- **Отзывчивость (Responsive):** Приложение одинаково хорошо работает на мобильных устройствах, планшетах и десктопах.
- **Производительность:** Backend эффективно кэширует внешние запросы, статика раздается через WhiteNoise.

## Что было исправлено (Bug Fixes)
- Закрыта уязвимость IDOR (ранее пользователи могли удалять чужие закладки).
- Исправлена ошибка N+1 в запросах Django ORM.
- Скрыты и обезопасены все секретные ключи (`SECRET_KEY`), включены жесткие ограничения CORS и `ALLOWED_HOSTS`.
- Исправлен баг, при котором плеер переставал проигрывать следующий аят.

## Что известно (Known Issues)
- Исходный код фронтенда (`shared.js`, `shared.css`) не минифицируется при сборке.
- Для получения Хадисов используется внешний CDN, который может иногда выдавать задержки.
- Не настроен PWA (Progressive Web App) для работы в полном оффлайн-режиме (без сети).
- Отсутствуют сложные Open Graph мета-теги для красивого отображения ссылок в социальных сетях.

## Что будет в версии 1.1 (Coming in v1.1)
- Поддержка PWA: возможность установить приложение на телефон и читать сохраненные суры без интернета.
- Внедрение бандлера (Vite/Webpack) для обфускации и сжатия клиентских файлов.
- Система уведомлений (Push Notifications) для напоминания о времени намаза.
- Мультиязычность интерфейса (i18n).
- Дополнительные переводы Корана и расширение базы хадисов.
